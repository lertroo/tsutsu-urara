# Tsutsu-Urara（津々浦ラ）

日本地図の上で、行ったところを記録するウェブページです。城・動物園・水族館・植物園・テーマパーク・博物館と美術館・空港・新幹線の駅・道の駅・県庁所在地・世界遺産・日本百景などを、地図と一覧から探して「行った」を付けられます。

- 公開ページ：https://lertroo.github.io/tsutsu-urara/
- 行った記録とマイスポットは、見ている人のブラウザ（localStorage）の中にだけ保存されます。サーバーには送られません。
- 静的なファイルだけで動きます。ビルドの手順はありません。

## アクセスの記録

公開ページでは、アクセスの日時・IPアドレス・おおよその地域・ブラウザの種類などを、自前の Cloudflare Worker に記録しています。

## ファイル

| 場所 | 中身 |
|---|---|
| `index.html` | 地図のページ（地図・検索・詳細） |
| `ashiato.html` | あしあと（行った所の記録を一覧で見る） |
| `kiroku.html` | 出力・保存（画像・年表を作る、記録のバックアップ、記録する人の管理） |
| `changelog.html` | 更新履歴（施設データの追加・修正の記録） |
| `about.html` | このサイト（更新情報・登録状況・採用基準・出典と免責） |
| `style.css` | 全ページで共通の見た目 |
| `site.js` | 全ページで共通の上部（文字の大きさ・表示モード・フォント・データ更新の日付） |
| `core.js` | 種類の表と行った記録（地図・あしあと・出力・保存・このサイトで共通） |
| `xport.js` | 画像を作る（地図・出力・保存で共通） |
| `data/` | 施設のデータと、県・区市町村の形 |
| `photos/` | 県庁舎などの写真（作者・ライセンスは `data/photos.js` とページの写真の下に記載） |

## 出典とライセンス

データと写真は、次のものをもとに作成・加工しています。それぞれの条件に従います。

- **OpenStreetMap**：© OpenStreetMap contributors（ODbL）。施設の位置と区域。
- **Wikidata**：CC0。施設の位置など。
- **Wikipedia 日本語版**：CC BY-SA 4.0。施設の選定、設置者の確認、記事へのリンク、日本百景の一覧。
- **国土交通省「国土数値情報」**：空港データ（C28-21）、鉄道データ（N02-20）、行政区域データ（N03）。Tsutsu-Urara が編集・加工して作成したもので、国土交通省が作成したものではありません。
- **市区町村の境界（東京都以外）**：国土数値情報（行政区域データ、2021年1月1日時点）を、スマートニュース メディア研究所が簡素化したもの（https://github.com/smartnews-smri/japan-topography）。
- **県の形**：japonyol.net「47都道府県のGeoJSON」をもとに、投影と簡略化をしたもの。
- **湖の輪郭**：Natural Earth（パブリックドメイン）。
- **道の駅**：mach-tools「道の駅オープンデータ」（CC BY 4.0）。
- **博物館の登録・指定の区分**：文化庁「全国の博物館」の一覧（2026年10月8日版）。
- **世界遺産**：ユネスコ世界遺産センター「日本」のページ。
- **写真**：Wikimedia Commons。写真ごとの作者とライセンス（CC BY / CC BY-SA / CC0 / パブリックドメイン / GFDL）は、`data/photos.js` とページの写真の下に記載しています。
